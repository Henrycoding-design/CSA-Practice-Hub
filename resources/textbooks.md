# Textbooks and Long-Form References

## Official

- [AP Computer Science A Course and Exam Description](https://apcentral.collegeboard.org/media/pdf/ap-computer-science-a-course-and-exam-description.pdf)
- [Java Quick Reference](https://apcentral.collegeboard.org/media/pdf/ap-computer-science-a-java-quick-reference.pdf)

## College Board

- Use the Course and Exam Description for topic scope.
- Use the Java Quick Reference to avoid studying library methods that are outside the exam.

## Practice

- [CSAwesome 2](https://runestone.academy/runestone/books/published/csawesome2/index.html)
- [CSAwesome v1](https://runestone.academy/ns/books/published/csawesome/index.html)

## Selection Tips

- Choose one main textbook-style source; do not collect five and finish none.
- Prefer sources with runnable Java examples.
- For AP CSA, prioritize arrays, `ArrayList`, strings, classes, inheritance, recursion, and 2D arrays.
