# Last-Minute AP CSA Review ("Don't Panic")

The exam is tomorrow (or very soon). Here is your high-impact checklist.

## 🚨 The Top 5 Concepts to Remember
1.  **Bounds Checking**: Always check `i < arr.length` or `i < list.size()`.
2.  **String Equality**: Use `str1.equals(str2)`, NEVER `str1 == str2`.
3.  **ArrayList Mutation**: If you remove an element while looping, you MUST decrement the index (`i--`) or use an Iterator.
4.  **Integer Division**: `5 / 2` is `2`. `5 / 2.0` is `2.5`.
5.  **Constructor Rules**: Subclass constructors always call `super()` first, even if you don't write it.

## 📝 Exam Day Pacing
- **Read the FRQ carefully**: Underline what the method MUST return.
- **Don't get stuck**: If a recursion MCQ is taking 5 minutes, guess and move on.
- **Check your semicolons**: Simple syntax errors shouldn't lose you points, but they add stress.
