# 1-Month AP CSA Study Plan

This plan is for students who have a full month to prepare. It balances foundational concepts with intensive practice.

## Weekly Breakdown

| Week | Focus Area | Key Concepts | Recommended Practice |
| :--- | :--- | :--- | :--- |
| **Week 1** | Foundations & Control | Primitive Types, Boolean Logic, If-Statements, Loops | MCQ Practice on Unit 1-4 |
| **Week 2** | Objects & Classes | Constructors, Methods, `this`, Static vs. Instance | Write 2 simple classes from scratch |
| **Week 3** | Data Structures | Arrays, `ArrayList`, 2D Arrays | FRQ Question 1 & 4 focus |
| **Week 4** | Advanced & Review | Inheritance, Recursion, Final Mock Exam | Full-length timed practice |

## Goals for this Month

- [ ] Complete all MCQ units on AP Classroom.
- [ ] Understand the difference between `==` and `.equals()`.
- [ ] Be able to traverse a 2D array using nested loops.
- [ ] Master the `ArrayList` methods: `add`, `get`, `set`, `remove`, `size`.
