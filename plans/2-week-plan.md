# 2-Week AP CSA High-Yield Plan

Two weeks left? It's time to prioritize the topics that appear most frequently on the exam.

## High-Yield Schedule

| Day | Topic | Action Item |
| :--- | :--- | :--- |
| **Day 1-2** | Array/ArrayList Traversal | Practice FRQ Question 1 (Methods and Control Structures). |
| **Day 3-4** | Class Design & Inheritance | Practice FRQ Question 2 (Class Writing). |
| **Day 5-6** | String Manipulation | Practice logic for `substring`, `indexOf`, and `equals`. |
| **Day 7-8** | 2D Arrays | Practice FRQ Question 4 (2D Array traversal). |
| **Day 9-10** | Recursion & Searching | Trace at least 10 recursion problems. |
| **Day 11-12** | Full Mock Exam | Take a timed, 3-hour practice test. |
| **Day 13-14** | Weak Spot Cleanup | Review the `error-log/common-errors.md`. |

## Pacing Strategy
- **MCQ**: 90 minutes for 40 questions (~2.25 mins per question).
- **FRQ**: 90 minutes for 4 questions (~22 mins per question).
