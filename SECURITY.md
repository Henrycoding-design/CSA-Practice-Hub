# Security Policy

AP CSA Practice Hub is an educational repository, but security and privacy still matter.

## Sensitive Data

No sensitive data should ever be committed. Do not include:

- Passwords, API keys, tokens, or credentials.
- Private student information.
- Unreleased exam material.
- Personal notes that identify students without consent.
- Local machine paths that reveal private information.

If sensitive data is committed by mistake, remove it immediately and open an issue so maintainers can review the exposure.

## Reporting Vulnerabilities

Report vulnerabilities through GitHub Issues. Include:

- A short description of the issue.
- The affected file, workflow, or documentation page.
- Steps to reproduce when applicable.
- Suggested remediation if you know one.

For privacy concerns, include only the minimum information needed for maintainers to act.
