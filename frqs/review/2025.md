# 2025 Simulated FRQ Review: Traps & Pitfalls

## Question 1: Data Management (cleanData)

### Frequent Wrong Answers
- **Skipping elements**: Many students forget `i--` after `list.remove(i)`.
- **String comparison**: Using `== ""` instead of `.length() == 0`.
- **Order of operations**: Checking `.length() == 0` *before* checking `== null`.

### Common Traps
- **The Shifting List**: Removing elements from an `ArrayList` while moving forward in a loop is the classic trap for this question type.
- **Null Safety**: Students often forget that `null` doesn't have methods, so calling `.length()` on a null reference crashes the program.

### Why They are Wrong
- **Skipping**: When you remove index `1`, the old index `2` becomes the new index `1`. If your loop then moves to `i=2`, you never checked the element that shifted down.
- **Null Safety**: Short-circuit evaluation (`||`) is your friend. You must check `data.get(i) == null` first because if it IS null, Java won't even look at the second part (`data.get(i).length() == 0`), preventing a `NullPointerException`.
