# 2025 FRQ Review

Use this page after attempting the 2025 FRQs and scoring with the official guidelines.

## High-Value Review Questions

- Did your response satisfy the full prompt, not just the examples?
- Did each method return the correct type and avoid unnecessary output?
- Did collection access use the correct syntax: `arr[i]` for arrays and `list.get(i)` for `ArrayList`?
- Did you avoid changing persistent data unless the prompt asked for mutation?

## Common Point Losses

- Confusing array access and `ArrayList` access.
- Writing extra code that has side effects.
- Declaring a variable in the wrong scope.
- Returning a value from a `void` method or constructor.
- Calling methods on `null` references.

## Fix Pattern

1. Compare your response to the rubric category by category.
2. Label each missed point as syntax, logic, state, or tracing.
3. Choose one missed part and rewrite it from scratch.
4. Re-test with a small case and a boundary case.
5. Add the root cause to the error log.
