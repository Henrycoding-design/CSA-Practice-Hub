# 2022 FRQ Review

Use this page after attempting the 2022 FRQs and scoring with the official guidelines.

## High-Value Review Questions

- Did your code match every required method signature?
- Did every loop use the correct bound for the data structure?
- Did you distinguish returning a value from changing object state?
- Did you test more than the prompt's first sample case?

## Common Point Losses

- Off-by-one errors in array or list traversal.
- Forgetting to initialize an accumulator before a loop.
- Using `==` for string content comparison.
- Returning too early inside a loop.
- Updating a local variable when the object field should change instead.

## Fix Pattern

1. Circle the first line where your trace differs from the expected behavior.
2. Write the missing condition or update in plain English.
3. Patch only that logic.
4. Re-trace the same test case.
5. Add the mistake to your error log if it appears twice.
