# 2023 FRQ Review

Use this page after attempting the 2023 FRQs and scoring with the official guidelines.

## High-Value Review Questions

- Did you call provided methods exactly as named?
- Did you avoid assuming hidden fields or methods exist?
- Did each part solve the requested task, not a nearby task?
- Did your code preserve the order of strings, arrays, or list elements when required?

## Common Point Losses

- Treating a method call as a field access.
- Mutating an `ArrayList` while using an enhanced `for` loop.
- Calling `substring` with an ending index that is one too small or too large.
- Dropping a required return for one branch.
- Confusing the sample case with the full set of valid inputs.

## Fix Pattern

1. Rewrite the prompt requirement as a boolean condition or loop goal.
2. Build the smallest test case that exposes your mistake.
3. Repair the condition, bound, or update step.
4. Rescore only the affected rubric row.
