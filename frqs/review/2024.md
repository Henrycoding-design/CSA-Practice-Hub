# 2024 FRQ Review

Use this page after attempting the 2024 FRQs and scoring with the official guidelines.

## High-Value Review Questions

- Did object state persist across method calls when the prompt required it?
- Did each helper variable have one clear meaning?
- Did you check boundaries such as zero, first index, and last index?
- Did 2D array code keep row and column roles separate?

## Common Point Losses

- Using `array[0].length` as the row count.
- Forgetting that `ArrayList.remove` shifts later elements left.
- Recomputing a value but never storing or returning it.
- Creating a new object when the existing object should be modified.
- Missing the final comparison after a loop ends.

## Fix Pattern

1. Draw the state of the object or array before the method runs.
2. Trace each loop iteration in a table.
3. Mark where the expected state and actual state diverge.
4. Rewrite the smallest incorrect block.
