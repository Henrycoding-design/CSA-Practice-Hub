# 2022 FRQ Answer Guide

Status: complete companion guide. Use it with the official 2022 College Board prompt and scoring guidelines in `frqs/questions/links.md`.

## Answer Workflow

1. Read the class header, instance variables, and method signatures before writing code.
2. Underline every return value, side effect, and precondition.
3. Write simple Java that matches the required method signature exactly.
4. Trace with the sample input from the prompt.
5. Score each part against the official rubric.

## Solution Checkpoints

| Question | What to verify before scoring |
| :--- | :--- |
| Q1 | Method signatures match, loops terminate, return values cover every branch. |
| Q2 | Constructor or class behavior preserves object state and uses instance variables correctly. |
| Q3 | Array or `ArrayList` traversal handles first, last, empty, and shifted-element cases. |
| Q4 | 2D array traversal uses row and column bounds correctly and avoids swapped indices. |

## Scoring Notes

- Award yourself points only for behavior the rubric explicitly credits.
- Do not give credit for code that works only for the sample case.
- Mark one repeated syntax issue once, then focus on the logic points.
- If your code changes persistent data that should not change, flag it before scoring.
