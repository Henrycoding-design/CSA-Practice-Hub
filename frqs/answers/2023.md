# 2023 FRQ Answer Guide

Status: complete companion guide. Use it with the official 2023 College Board prompt and scoring guidelines in `frqs/questions/links.md`.

## Answer Workflow

1. Copy the required method headers exactly into your practice space.
2. Translate each part of the prompt into one or two plain-English steps.
3. Code the simplest correct version before trying to shorten anything.
4. Trace at least one normal case and one edge case.
5. Compare against the scoring guidelines line by line.

## Solution Checkpoints

| Question | What to verify before scoring |
| :--- | :--- |
| Q1 | Helper method calls use the given API exactly and handle all prompt conditions. |
| Q2 | String operations preserve order, avoid off-by-one errors, and use `.equals` when needed. |
| Q3 | Collection updates do not skip elements after removal or insertion. |
| Q4 | Nested loops visit every required cell once and combine results in the correct variable. |

## Scoring Notes

- Treat official sample output as a test, not as the whole problem.
- Look for partial credit in each part separately.
- If a later line depends on an earlier mistake, note whether the rubric allows consistency credit.
- Record the highest-value missed point in your mistake log.
