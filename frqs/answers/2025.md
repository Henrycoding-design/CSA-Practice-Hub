## Question 1: Data Management (cleanData)

### Explanation
This method cleans an `ArrayList` by removing unwanted strings (null or empty) and counting the removals.

### Logic Separation
1.  **Iteration**: Move through the list using a standard for-loop.
2.  **Validation**: Check each element for `null` OR `length == 0`.
3.  **Mutation**: Remove the invalid element and **decrement the index counter** to handle the list shift.
4.  **Reporting**: Return the total count of removals.

### Sample Flow
- **Input**: `["apple", null, "", "banana"]`
- **Process**:
    - `i=0`: "apple" (Keep)
    - `i=1`: null (Remove, `count=1`, `i` becomes `0`)
    - `i=1`: "" (Remove, `count=2`, `i` becomes `0`)
    - `i=1`: "banana" (Keep)
- **Output**: `2` (and list is `["apple", "banana"]`)

### Canonical Solution
```java
public int cleanData(ArrayList<String> data) {
    int count = 0;
    for (int i = 0; i < data.size(); i++) {
        if (data.get(i) == null || data.get(i).length() == 0) {
            data.remove(i);
            count++;
            i--; 
        }
    }
    return count;
}
```
