# 2025 FRQ Answer Guide

Status: complete companion guide. Use it with the official 2025 College Board prompt and scoring guidelines in `frqs/questions/links.md`.

## Answer Workflow

1. Read the complete prompt first; the 2025 materials use the current released College Board wording.
2. Write method headers exactly as provided.
3. Separate required behavior from examples.
4. Trace each part using the prompt examples and one extra edge case.
5. Score with the official guidelines before reading any sample responses.

## Solution Checkpoints

| Question | What to verify before scoring |
| :--- | :--- |
| Q1 | Control flow covers all prompt cases and returns the required result type. |
| Q2 | Class or object behavior preserves encapsulated state and uses constructors/methods correctly. |
| Q3 | Arrays or `ArrayList` logic handles traversal, mutation, and accumulation safely. |
| Q4 | Nested data logic handles every required row, column, or object relationship. |

## Scoring Notes

- The official rubric takes precedence over any alternate explanation.
- A response can earn partial credit even if it is not elegant.
- Avoid extra output, extra precondition checks with side effects, or mutation of data the prompt expects to remain unchanged.
- Add every repeated mistake to `templates/mistake-log-template.md`.
