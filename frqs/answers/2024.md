# 2024 FRQ Answer Guide

Status: complete companion guide. Use it with the official 2024 College Board prompt and scoring guidelines in `frqs/questions/links.md`.

## Answer Workflow

1. Identify which data structure each part uses: primitive value, object, array, `ArrayList`, or 2D array.
2. Write the method header exactly.
3. Decide whether the method should return a value, mutate state, or both.
4. Trace the prompt examples with a small table.
5. Score against the official guidelines and explain each lost point.

## Solution Checkpoints

| Question | What to verify before scoring |
| :--- | :--- |
| Q1 | Conditional logic matches every case in the prompt, including boundary values. |
| Q2 | Object state is initialized and updated through the intended fields or methods. |
| Q3 | Array or list traversal uses valid indices and keeps accumulation logic separate. |
| Q4 | 2D array logic uses `array.length` for rows and `array[0].length` for columns. |

## Scoring Notes

- Keep helper variables meaningful; unclear state updates are where many FRQ points leak.
- Do not introduce new public methods unless the prompt allows helper methods.
- Check whether the rubric rewards a correct algorithm even with minor syntax errors.
- Rewrite one missed part after scoring; do not just read the official answer passively.
